Select events and optional action/result filters. Copy the compressed value into the Cloudflare secret NOTIFICATION_CONFIG.

This page runs in your browser. It does not read or change your Worker or require credentials. Selections are saved on this device.

GitHub must also be configured to deliver the selected events. Some events require organization or GitHub App hooks; this bridge only accepts payloads for its configured repository. Ping is always acknowledged without a channel message.

Apply to Cloudflare

Worker → Settings → Variables and Secrets → add a secret named NOTIFICATION_CONFIG, paste the copied gz:… value, and deploy.

Or download the secret and run from this project:

bunx wrangler secret put NOTIFICATION_CONFIG < notification-config.txt

The smaller value uses gzip + base64url. Both compressed values and plain JSON are supported, with a 5 KiB secret limit. Explicit rules replace the old pipeline setting. All selected filters must match; an empty selected-actions list sends nothing. Your current settings stay active until you apply this secret.
