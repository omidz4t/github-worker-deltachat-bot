GitHub → Delta Chat

Let’s have a free feed of your GitHub project in Delta Chat.

A webhook bridge that sends repository activity—commits, issues, pull requests, and releases—to an encrypted Delta Chat broadcast channel.

GitHub → Worker → WebSMTP → Delta Chat channel

What it uses

Cloudflare Worker
Receives webhooks and checks GitHub’s HMAC-SHA256 signature.
Durable Object
Stores subscribers and queued messages; retries delivery and filters duplicate events.
OpenPGP.js
Signs and encrypts messages; handles Delta Chat’s SecureJoin handshake.
WebIMAP / WebSMTP
Reads join requests and submits mail through a compatible server such as Madmail.
Bun + TypeScript
Runs local setup, checks, and deployment scripts.

Setup

You need Bun, a Cloudflare account, a compatible mail server, and permission to add a GitHub repository webhook.

  1. Install and configure. 
    git clone https://github.com/omidz4t/github-worker-deltachat-bot.git
cd github-worker-deltachat-bot
bun install

    Create a local .env with your server and Delta Chat contact invitation:

    WEBIMAP_HOSTNAME=https://your-mail-server
CHATMAIL_CONTACT_INVITE="your-contact-invite-link"
BOT_NAME="Madmail Bot"
CHANNEL_NAME="Madmail GitHub"
BOT_LOGO="https://madmail.chat/favicon.png"
CHANNEL_LOGO="https://madmail.chat/favicon.png"

    Names and logos are configurable. Logos accept an HTTPS URL or a local PNG/JPEG path (max 3.75 KiB); both default to the Madmail icon and are saved in Cloudflare secrets.

    Set GITHUB_REPOSITORY in wrangler.jsonc. Update the Worker URLs in scripts/ for your deployment.

  2. Create the account and channel, then deploy. Keep the contact’s Delta Chat client online for the handshake. 
    bunx wrangler login
bun run chatmail:setup
bun run scripts/create-channel.ts
bun run scripts/push-secrets.ts
bun run deploy
bun run channel bootstrap
bun run channel info

    The last command returns the channel join link. If the handshake times out, rerun setup; use bun run chatmail:setup --legacy for the compatible handshake.

  3. Add the GitHub webhook. In your repository’s Settings → Webhooks, set:

    URL: https://YOUR-WORKER.workers.dev/github/webhook
    Content type: application/json
    Secret: the value in local .env.github-webhook-secret
    Select your events; enable SSL verification and Active.

    Check delivery with bun run webhook:test. Join requests are checked every minute.
