Stay in the conversation.

Follow the work from the messenger you already use.

01 / VERIFIED

Trust the source

HMAC-SHA256 validates GitHub deliveries. A repository allowlist keeps notifications focused on your project.

02 / ENCRYPTED

Keep updates private

OpenPGP.js signs and encrypts channel messages. Subscribers cannot see one another’s addresses.

03 / PERSISTENT

Keep the queue moving

A Durable Object stores pending notifications, retries failed submissions, and deduplicates GitHub delivery IDs.

Run it yourself

A small bridge. Your own channel.

01

Configure the Worker

Clone the repository, install with Bun, and follow the README to configure your WebIMAP server and contact invitation locally.

02

Create your channel

Generate the channel configuration and signing secret. Upload credentials to Cloudflare secrets, then deploy the Worker.

03

Connect GitHub

Add a JSON webhook to your repository using your Worker URL and signing secret. Select the events you want to follow.

git clone https://github.com/omidz4t/github-worker-deltachat-bot.git
cd github-worker-deltachat-bot
bun install

Account credentials, contact invitations, and signing secrets belong in local ignored files and Cloudflare secrets.
